# Numbers 3 — 1日1口

iPhoneのSafariから使う、ナンバーズ3（ストレート・1抽せん1口）の個人用Webアプリです。

## 主な機能

- 2つの公式サイトで一致した抽せん結果だけを使用
- 直近30・50・100・200・500回を選べる4方式の分析
- 予想の確定・取り消し・購入記録・収支確認
- 予想と収支のバックアップ／復元
- iPhoneのホーム画面への追加とオフライン表示

予想・購入・収支はSafariの端末内だけに保存され、GitHubへは送信されません。公開されるのはアプリ本体と過去の公式抽せん結果だけです。

## GitHub Pagesでの公開

1. GitHubで公開リポジトリを作成します。リポジトリ名は `numbers3-web` などで構いません。
2. このフォルダの内容を `main` ブランチへアップロードします。
3. リポジトリの **Settings → Pages → Build and deployment → Source** で **GitHub Actions** を選びます。
4. **Actions** の `Update data and publish GitHub Pages` を開き、`Run workflow` を1回実行します。
5. 完了後、Settings → Pages に表示されるURLをiPhoneのSafariで開きます。

平日の21:30（日本時間）に自動更新します。PayPay銀行と楽天の結果が一致した場合だけデータを更新し、そのままWeb版を再公開します。403・429などのアクセス制限が返った場合は回避や再試行をせず、その回の更新を中止します。

## iPhoneへの追加

Safariで公開URLを開き、共有ボタンから **ホーム画面に追加** を選びます。Safariの履歴・Webサイトデータを消すと予想や収支も消えるため、「予想と収支」画面から時々バックアップを書き出してください。

## データ元

- PayPay銀行 ナンバーズ3当せん番号案内（CSV）
- 楽天×宝くじ ナンバーズ3過去の当せん番号

過去の傾向は次回の当せんを保証しません。購入はご自身の判断で行ってください。
